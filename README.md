# Tijn's Burger Place

Een kleurrijk restaurant tycoon spel voor kinderen (8-10 jaar). Open `index.html` in de browser.

- Klanten komen binnen en gaan aan tafel zitten
- Koks maken het eten in de keuken, obers brengen het naar de tafel
- Tik op het geld (in euro's) dat klanten achterlaten
- Koop koks, obers, kassamedewerkers, nieuwe keukens, tafels en uitbreidingen

Voortgang wordt automatisch opgeslagen in de browser.
